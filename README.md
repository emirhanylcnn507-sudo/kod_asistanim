# Projenin Adı: Kod-Asistan v0.1
## Projenin Amacı: Kullanıcıdan alınan n değerine kadar olan ardışık sayıların toplamını hesaplayan bir dijital asistan tasarlamak.
## Projenin Hedefleri: 
v1.0 Sürümü: 1'den n'e kadar olan ardışık sayıların toplamını döngü kullanarak hesaplamak ve ekrana yazdırmak.
v2.0 Sürümü: Kullanıcının girdiği sayıları ve sonuçları hafızada saklamak.
## Projenin Kapsamı: 
Kullanıcıdan n değeri okunur ve toplam 0, sayaç 1 olarak başlatılır.
Sayaç n değerinden küçük olduğu sürece döngü çalışır (Kritik Eşik / Döngü Koşulu: Sayaç < n).
şart saglandıkça sayılar toplanır ve sayaç artırılır.
Şart sağlanmadığında toplam sonucu ekrana yazdırılır ve program durur .
